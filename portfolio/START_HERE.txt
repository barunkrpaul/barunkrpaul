WHAT IS IN THIS FOLDER
---------------------------------------------------------------------
dist/            The finished website, ready to upload. Nothing to build.
src/             The source. Edit text here (see "CHANGING THE SITE").
firebase.json    Hosting settings (clean addresses, caching, security).
.firebaserc      Links this folder to your Firebase project. EDIT ONCE.
package.json     Commands: npm run build, npm run deploy.
README.md        Developer notes.

(.firebaserc starts with a dot, so the Mac hides it. In Finder press
 Cmd + Shift + . to show hidden files.)


A. FIRST TIME: PUT THE SITE ONLINE (about 10 minutes)
---------------------------------------------------------------------
1. Firebase project: already created (portfolio-e1264).
   Make sure you are signed in to Firebase with the Google account that
   owns it.

2. Project ID and site: already set. .firebaserc points to the project
   portfolio-e1264, and firebase.json uploads to the site  portfoliodp

3. Install the Firebase tools (skip if you already did this for
   Gymlive):
   - Node.js (LTS) from https://nodejs.org
   - Terminal:   npm install -g firebase-tools
   - Terminal:   firebase login
     (use the same Google account as in step 1)

4. Upload: double-click  "Deploy to Firebase.command"  in this folder.
   The very first time, macOS may refuse a downloaded script: right-click
   it, choose Open, then Open again. A Terminal window opens, a browser
   asks you to sign in to Google if needed, and the site is uploaded.

   (Or by hand: in Terminal go into this folder and run
       firebase deploy --only hosting )

5. Open the address Firebase prints, e.g.
       https://portfoliodp.web.app
   That is your live portfolio.


B. CHANGING THE SITE LATER
---------------------------------------------------------------------
Almost every word on the site is in two files:
   src/data/projects.ts   every project: text, numbers, links, status
   src/data/site.ts       names, tagline, bios, services, contact email

After editing:
   First time only, in this folder:   npm install
   Every time:                        npm run deploy
   (or double-click "Deploy to Firebase.command": once node_modules
    exists it rebuilds the site before uploading)
(npm run deploy builds the site into dist/ and uploads it.)

Tip: npm install creates a large node_modules folder. Inside Google
Drive that means thousands of files to sync. If Drive gets slow, keep a
working copy of this folder outside Drive (for example in Documents) and
copy it back to Drive as a backup.


ADDING SCREENSHOTS
Put screenshots in  src/assets/work/<project>/  (the folder names are the
project slugs in src/data/projects.ts, e.g. hsms-hardware, leave-management).
Name them 01-..., 02-... in the order you want. Then  npm run deploy.
Hide personal data (names, phone numbers) before taking a screenshot.


C. YOUR OWN DOMAIN (optional, later)
---------------------------------------------------------------------
Firebase console > Hosting > Add custom domain, and follow the steps.
Firebase gives the DNS records to add at your domain registrar. HTTPS
is set up for you.


D. THE NAME PREVIEW SWITCHER
---------------------------------------------------------------------
Visitors only see the first name in the list (k = 2). To compare all
names on the live site in YOUR browser, open:
       https://<your-site>.web.app/?names
and to hide the switcher again:
       https://<your-site>.web.app/?names=off
When you have chosen a name: in src/data/site.ts move it to the top of
"brands", set showBrandSwitcher = false, then npm run deploy.
